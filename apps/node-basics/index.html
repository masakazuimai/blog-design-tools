このアプリについて

    
    
      
  • fs（ファイル操作）・path・モジュール（CJS/ESM）・process・イベントループ・Stream/Bufferまで、Node.js固有の基礎APIを20問で総ざらいできます
    • 
      
  • Q1・Q6・Q9・Q13・Q16は記事版のサンプル5問と同じ問題、残り15問はアプリ限定ドリルです
    • 
      
  • コードはブラウザ内の仮想Node環境（fs・path・process・requireなどの主要APIを再現した実行環境）で動き、仮想ファイルへの書き込みはファイルパネルにライブ反映されます（登録・インストール不要）
    • 
      
  • 仮想環境はNode.jsの完全な再現ではありません。importはトップレベルの静的な形式のみ対応し、httpサーバーやExpressは記事版のローカル実行課題で体験できます
    • 
      
  • 「✓できた / △あとで復習」の自己判定はこの端末に自動保存され、復習リストだけを解き直せます
    •
