このアプリについて

    
    
      
  • 見出し・段落・リンク・画像・リスト・表・フォーム・セマンティックタグまで、HTMLの基礎を20問で総ざらいできます
    • 
      
  • Q1〜Q6は記事版と同じ問題、Q7〜Q20はアプリ限定ドリル（input の type / label と for / thead と scope / 入れ子リスト / alt / target と rel / article と section / fieldset / dl / head のメタ情報など）です
    • 
      
  • エディタにはHTMLのひな形が入っています。入力すると下のプレビューへ自動で反映され、「お手本」タブに切り替えると解答例の表示と見比べられます（登録・インストール不要）
    • 
      
  • 「✓できた / △あとで復習」の自己判定はこの端末に自動保存され、復習リストだけを解き直せます
    • 
    

    
各問題の詳しい解説は、記事版「HTML基礎練習問題｜初心者が実践で学べる！レイアウトからリンク設定まで完全解説」にまとめています。書けるようになったら、見た目を整えるCSS基礎練習アプリ（24問）へどうぞ。
