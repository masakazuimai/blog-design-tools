How to Use & FAQ

How to use Video Scenario Maker, plus frequently asked questions.

Video Scenario Maker helps you plan an AI video scene by scene. Set each scene's length, reference image, dialogue and camera, check the pacing on a timeline, and copy English prompts you can paste straight into AI video generators. It also exports a prompt for AI music generators and SRT subtitles.

🖱️ Basic steps

  1. Set the project. Choose the aspect ratio, visual style, mood and dialogue language. These are included in every scene's prompt.
  2. Lay out the scenes. Add clips with "+ Add scene" and drag the right edge of a clip to set its length (0.5-second steps).
  3. Fill in each scene. Select a clip and set its reference image, description, dialogue, shot size and camera in the inspector. Reorder with "← Earlier" and "Later →".
  4. Pick the voices. If there is dialogue, open the Voices tab and set a gender, age and tone for each speaker.
  5. Check the timing. Play the preview to make sure each line has time to be read and cuts aren't too quick.
  6. Copy the prompts and paste them into an AI video or music generator.

✍️ Tips for prompts that work

  • Keep one action per scene. Split "walks in, turns around and waves" into separate scenes for more reliable results.
  • Use the menus for camera and lighting. Options like "Dolly in" or "Golden hour" are written as phrasing video models understand well.
  • Want the subject to move? Keep the camera static. When the camera moves, the model can use that motion instead of animating the subject.
  • Turn on "no on-screen text" if you don't want the model to draw text. Adding subtitles later from the SRT file is more reliable.

❓ FAQ

Which AI video generators does it work with?

It writes general-purpose English prompts that don't depend on any one service's syntax, so they work with text-driven video generators such as Sora and Veo. Use Per scene for services that generate one shot at a time, and Full timeline for services that can handle longer clips with time cues.

Can I write descriptions in another language?

Yes, but free-text fields are output exactly as you type them; the tool does not translate. Menu options such as shot size and camera movement are always written as standard English phrasing. Write dialogue in the language you want it spoken in.

How long should each scene be?

Each service and plan limits how long a single generation can be. Split your scenes to fit the limit of the service you use. The tool shows a warning when a scene is longer than 10 seconds.

Can I set the voice for each speaker?

Yes. The Voices tab lists every speaker in your scenes. Choose a gender, age, tone and pace, plus optional notes, and the voice is added to that speaker's lines (for example: a calm, middle-aged male voice). Lines without a speaker are grouped as the narrator.

How are reference images used?

When a scene has an image, its prompt says to use the attached reference image. The image itself is not part of the prompt, so attach the same image when you paste the prompt into a video generator. The preview shows the image as well.

What can I do with the SRT subtitles?

Scenes with dialogue become a subtitle file with each scene's start and end times. You can upload it to YouTube as captions or import it into any video editor that supports SRT.

Are my inputs and images uploaded anywhere?

No. Everything, including images and audio, is stored only in your browser (IndexedDB). To move a project to another device, save it as JSON from the File tab. JSON files do not include images or audio.
