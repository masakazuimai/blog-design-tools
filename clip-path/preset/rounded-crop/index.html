CSS 角丸で切り抜く方法

clip-path: inset(... round) で角丸の四角形にトリミングするコードを、実物プレビュー付きでコピーできます。

角丸で切り抜くには clip-path: inset(0 round 24px) を指定します。border-radius と違いはみ出した子要素や影も角丸に沿って切れるのが利点です。サムネイルやカードのトリミングに使えます。下にコピペ用コードを用意しました。

角丸でトリミング

CARD

CSS

.rounded-crop {
  clip-path: inset(0 round 24px);
  -webkit-clip-path: inset(0 round 24px);
}

余白をつけて角丸で切り抜き

CARD

CSS

.rounded-crop-inset {
  clip-path: inset(8% round 16px);
  -webkit-clip-path: inset(8% round 16px);
}

ポイントと注意点

  • border-radius との違い：clip-path は実際に切り抜くので、子要素や影もきれいに角丸へ収まります。
  • 余白の指定：inset(8% round 16px) の最初の値が内側の余白（上右下左）です。
  • 角丸の大きさ：round の後ろの値で丸みが決まります。round 50% にすると円・楕円に近づきます。微調整は clip-path ジェネレーター の「inset」タイプが便利です。
