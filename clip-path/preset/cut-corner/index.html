CSS 角カットの作り方

clip-path で角を斜めに切る（コーナーカット・隅切り）コードを、実物プレビュー付きでコピーできます。

角を斜めにカットするには clip-path: polygon(...) で切りたい角だけ2点に分けます。calc(100% - 24px) のようにpx指定にすると、要素サイズが変わってもカット量が一定になります。SF・テック系のカードやボタンに人気です。下にコピペ用コードを用意しました。

右上1隅をカット

CARD

CSS

.cut-corner {
  clip-path: polygon(0 0, calc(100% - 28px) 0, 100% 28px, 100% 100%, 0 100%);
  -webkit-clip-path: polygon(0 0, calc(100% - 28px) 0, 100% 28px, 100% 100%, 0 100%);
}

対角2隅をカット（右上＋左下）

CARD

CSS

.cut-corner-2 {
  clip-path: polygon(0 0, calc(100% - 28px) 0, 100% 28px, 100% 100%, 28px 100%, 0 calc(100% - 28px));
  -webkit-clip-path: polygon(0 0, calc(100% - 28px) 0, 100% 28px, 100% 100%, 28px 100%, 0 calc(100% - 28px));
}

ポイントと注意点

  • px指定がおすすめ：calc() でpx指定すると、横長・縦長の要素でもカット量が一定になります。
  • 枠線（border）が消える：clip-pathで切ると通常のborderは切り口に出ません。枠線風にしたいときは背景を2枚重ねるなどの工夫が必要です。
  • 切る角を選ぶ：カットしたい角だけ2点に分ければ、好きな組み合わせで隅切りできます。微調整は clip-path ジェネレーター が便利です。
