CSS シェブロンの作り方

clip-path で「>」型の矢羽根・パンくずを作るコードを、実物プレビュー付きでコピーできます。

シェブロン（>型）は clip-path: polygon(0 0, 75% 0, 100% 50%, 75% 100%, 0 100%, 25% 50%) で作れます。横に並べるとパンくずリストや進捗ステップ（矢羽根）になります。下にコピペ用コードを用意しました。

右向きシェブロン

HOME

CSS

.chevron {
  clip-path: polygon(0 0, 75% 0, 100% 50%, 75% 100%, 0 100%, 25% 50%);
  -webkit-clip-path: polygon(0 0, 75% 0, 100% 50%, 75% 100%, 0 100%, 25% 50%);
}

左向きシェブロン

BACK

CSS

.chevron-left {
  clip-path: polygon(25% 0, 100% 0, 75% 50%, 100% 100%, 25% 100%, 0 50%);
  -webkit-clip-path: polygon(25% 0, 100% 0, 75% 50%, 100% 100%, 25% 100%, 0 50%);
}

ポイントと注意点

  • パンくずに並べる：右向きシェブロンを横並びにし、margin-left をマイナスにして左のくぼみに重ねると矢羽根が連続します。
  • 尖りの強さ：先端の 100% 50% と くぼみ 25% 50% を動かすと、尖り具合が変わります。
  • 文字の余白：左右がくぼむので padding を左右に多めにとると文字が切れません。微調整は clip-path ジェネレーター が便利です。
