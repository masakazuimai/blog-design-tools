CSS ジグザグの作り方

clip-path で波状・切手風のギザギザ縁を作るコードを、実物プレビュー付きでコピーできます。

ジグザグの縁は clip-path: polygon(...) の頂点を一定間隔で上下させて作ります。下辺だけギザギザにすればセクションの区切りに、上下をギザギザにすれば切手・クーポン風の帯になります。下にコピペ用コードを用意しました。

}

ポイントと注意点

  • 山の数：頂点の刻み幅で決まります。例は5%刻み。細かくするほど頂点が増えコードが長くなります。
  • ギザギザの深さ：谷側の値（80% や 10%）を動かすと深さが変わります。
  • 背景として使う：区切りだけ欲しいときは、ジグザグを付けた擬似要素や帯を背景の上に重ねると実装しやすいです。微調整は clip-path ジェネレーター が便利です。
