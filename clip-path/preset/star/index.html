CSS 星の作り方

clip-path で星型（スター）を作るコードを、実物プレビュー付きでコピーできます。

星型は clip-path: polygon(50% 0%, 61% 35%, 98% 35%, 68% 57%, 79% 91%, 50% 70%, 21% 91%, 32% 57%, 2% 35%, 39% 35%) で作れます。10個の頂点（外側5・内側5）で五つ星になります。レビュー評価のスターやバッジに画像なしで使えます。下にコピペ用コードを用意しました。

五つ星

CSS

.star {
  clip-path: polygon(50% 0%, 61% 35%, 98% 35%, 68% 57%, 79% 91%, 50% 70%, 21% 91%, 32% 57%, 2% 35%, 39% 35%);
  -webkit-clip-path: polygon(50% 0%, 61% 35%, 98% 35%, 68% 57%, 79% 91%, 50% 70%, 21% 91%, 32% 57%, 2% 35%, 39% 35%);
}

六芒星（star of david）

CSS

.star-6 {
  clip-path: polygon(50% 0%, 63% 25%, 100% 25%, 75% 50%, 100% 75%, 63% 75%, 50% 100%, 37% 75%, 0% 75%, 25% 50%, 0% 25%, 37% 25%);
  -webkit-clip-path: polygon(50% 0%, 63% 25%, 100% 25%, 75% 50%, 100% 75%, 63% 75%, 50% 100%, 37% 75%, 0% 75%, 25% 50%, 0% 25%, 37% 25%);
}

ポイントと注意点

  • 正方形で使う：要素を正方形にすると整った星になります（縦横が違うと伸びます）。
  • 星評価：星を並べ、背景の塗り幅で評価の割合（例：☆3.5）を表現できます。
  • 微調整は clip-path ジェネレーター の「星」プリセットから頂点をドラッグできます。
