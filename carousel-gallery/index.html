カルーセル CSS サンプル集

カルーセルは、CSS の scroll-snap・@keyframes・3D の transform を使えば、JavaScript なしでも作れます。螺旋や無限ループなど60種を動かして選び、枚数や速さを変えて、HTML と CSS をそのままコピーできます。

カルーセルの種類から選ぶ

カードを押すと、大きな見本と設定とコードが開きます。

    カルーセルの種類と選び方

    カルーセルは、画像やカードを横（または縦・らせん）に並べて、送ったり流したりして見せる部品です。手で送る形はスクロールスナップ、自動で流す形は無限ループ、目を引きたい所には螺旋やカバーフローが向いています。

    スクロール連動や ::scroll-marker などの CSS がどのブラウザで動くかは Chrome for Developers の「CSS を使用したカルーセル」 と MDN の「CSS によるカルーセルの作成」 で確かめられます。書き出すコードは、動きを減らす設定の端末では止まった形で表示します。
