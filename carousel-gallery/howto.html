カルーセル CSS サンプル集の使い方

3つの手順で、カルーセルを自分のページに入れられます。ツールを開く

使い方

  1. 型を選ぶ：一覧から、螺旋・無限ループ・スクロールスナップなど使いたい型のカードを押します。
  2. 設定を変える：枚数・速さ・半径などのつまみを動かし、見本で動きを確かめます。
  3. コードをコピーして貼る：「コードをコピー」を押し、ページの貼りたい所に貼ります。カードの中身は自分の画像や文に差し替えます。

よくある質問

CSSだけでカルーセルは作れますか？

作れます。手で送る形は scroll-snap、自動で流す形は @keyframes、螺旋のような立体は 3D の transform で作れます。このツールの型のほとんどは JavaScript を使いません。JavaScript も使う型には「JS」の印を付けています。

自動で流れ続けるカルーセルはどれですか？

無限ループ（マーキー）と2段の逆向きループです。同じ並びを2回置き、半分の幅だけ動かしてつなぎ目を消しています。螺旋・トルネード・二重螺旋も自動で動き続けます。

スマホでスワイプして送れますか？

スクロールスナップ・ボタンと点で送る・中央が大きくなる・カバーフローは、指で横に送れます。螺旋の型は、幅が600px以下の画面では小さく表示します。

Safari や Firefox で動かない型はありますか？

ありません。ボタンと点で送る・中央が大きくなる・カバーフロー・パララックス・端でぼける、とスクロールで動く型は、Chrome・Edge では CSS で動き、まだ対応していないブラウザではコードの中の短い JS が同じ動きをします。

螺旋カルーセルはどうやって作っていますか？

1つの @keyframes で、高さ（translateY）と角度（rotateY）と半径（translateZ）を同時に動かし、カードごとに animation-delay を負の数でずらして、らせんの上に並べています。

動きを減らす設定の人にはどう見えますか？

書き出すコードには prefers-reduced-motion の指定が入っていて、自動で動く型は止まった形で表示します。

カードを自分の画像に変えるには？

コードの中の cg-card の要素に、img 要素や background-image を入れます。色のグラデーションは .cg-card の background で決めているので、画像に変えるときは消してかまいません。
