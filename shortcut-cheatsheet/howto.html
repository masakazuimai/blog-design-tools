ショートカットキー チートシート 使い方・FAQ

TOP
English

カテゴリ切替・マイ一覧づくり・自分のショートカット登録・印刷/PDF・画像書き出しまで、使い方とよくある質問をまとめました。

このツールは、Photoshop・Illustrator・Figma・Office などのショートカットキーをアプリ別に一覧表示し、★でよく使うキーを集めた自分専用の「マイ一覧」を作れる無料チートシートです。登録不要・ブラウザ内で完結します。

基本の使い方（5ステップ）

  1. アプリを選ぶ … トップから対象アプリ（Photoshop・Illustrator・Figma・Excel・Word・PowerPoint）を開きます。
  2. 探す … 左メニューのカテゴリ切替、または検索ボックスで目的のショートカットを絞り込みます。
  3. ★でマイ一覧に追加 … よく使うキーの☆を押すとマイ一覧に入ります。用途別「テンプレート」での一括追加や、自分のショートカット登録も可能です。
  4. 並べ替え … マイ一覧のカードをドラッグして使いやすい順に。並び順は自動保存されます。
  5. 書き出し … 「🖨 印刷 / PDF」または「🖼 画像（PNG）」で、自分専用のチートシートを書き出せます。

主な機能

  • マイ一覧：★で集めた自分専用のショートカット集。並べ替え・書き出し対応。
  • ショートカット登録：一覧にないキーや、自分で割り当てたキーを「＋ ショートカットを登録」から追加。キーは押して取得／手動入力の両対応。
  • テンプレート：「定番セット」「写真レタッチ」など用途別のおすすめを一括でマイ一覧に追加。
  • 印刷／PDF・画像書き出し：マイ一覧をチートシートとして印刷・PDF保存・PNG画像化。
  • Mac / Windows 切替：⌘⌥⇧ ↔ Ctrl/Alt/Shift をワンタップで切り替え。
  • 検索・自動保存：機能名で検索、並び順やお気に入りはこのブラウザに自動保存。

対応アプリ

Photoshop Illustrator Figma Excel Word PowerPoint

よくある質問（FAQ）

このツールは無料ですか？登録は必要ですか？

完全無料・登録不要です。すべてブラウザ内で動作し、入力データが外部に送信されることはありません。

「マイ一覧」とは何ですか？

★で集めた自分専用のショートカット集です。ドラッグで並べ替えでき、印刷やPNG画像として書き出せます。並び順・お気に入りはブラウザに自動保存されます。

一覧にないショートカットを追加できますか？

はい。「＋ ショートカットを登録」から機能名とキーを登録できます。登録分は「カスタム」カテゴリに入り、自動でマイ一覧にも追加されます。

Mac と Windows の表記は切り替えられますか？

左上のトグルで切り替えられます。Macは⌘⌥⇧、WindowsはCtrl/Alt/Shiftで表示されます。

作ったチートシートを印刷・保存できますか？

「印刷 / PDF」で印刷（PDF保存も可）、「画像（PNG）」で画像としてダウンロードできます。デスク横に貼ったり共有するのに便利です。

対応アプリは何ですか？

Photoshop・Illustrator・Figma・Excel・Word・PowerPoint に対応しています。今後さらに追加予定です。

表示されたショートカットが実際と違うことがありますか？

アプリのバージョンや個人のカスタム設定、Mac/Windowsの違いによって異なる場合があります。その場合は「＋ ショートカットを登録」で自分の環境に合わせて登録してください。
