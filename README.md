# Blog Design Tools

非エンジニアでもClaude Codeにプロンプトを投げるだけで作れるWebツール集です。

ほとんどのツールはHTML1ファイルで完結しており、ビルドツールやフレームワークは使っていません。一部のツールはビルドが必要で、そのソースは [`_src/`](./_src/) にあります。

## 技術構成

- HTML / CSS / JavaScript（バニラ）
- ビルドツールなし（`_src/` にソースを置く一部のツールを除く）

## 作り方

Claude Codeに作りたいツールを日本語で伝えるだけです。

## ライセンス

本リポジトリのコードは学習・参考目的でのみ利用できます。商用利用・再配布は禁止です。
