# Blog Design Tools

非エンジニアがClaude Codeにプロンプトを投げるだけで作ったWebツール集です。

すべてのツールはHTML1ファイルで完結しており、ビルドツールやフレームワークは使っていません。

## ツール一覧

| ツール | 説明 | URL |
|---|---|---|
| [見出しデザイン プレビューア](./heading-design-previewer/) | ブログの見出しデザインをプレビューしてCSS/HTMLをコピー | [デモ](https://masakazuimai.github.io/blog-design-tools/heading-design-previewer/) |

## 技術構成

- HTML / CSS / JavaScript（バニラ）
- ビルドツールなし
- GitHub Pages でホスティング

## 作り方

Claude Codeに作りたいものを日本語で伝えるだけです。

```
見出しデザインをプレビューできるWebアプリを1つのHTMLファイルで作ってください。
CSSをコピーできるボタンをつけて、WordPressのカスタムHTMLブロックに
そのまま貼れるようにしてください。
```
