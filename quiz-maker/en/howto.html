How to use Quiz Maker, a tool where you write your own questions with four choices (1 correct, 3 wrong) and get quizzed until you remember them.

How to use

  1. Press "New" to start a quiz set, or open a CSV / JSON file
  2. Add the question, the correct answer, three wrong choices and an optional explanation. "Add & next" (Ctrl+Enter) lets you keep going
  3. Use "Today's review" to answer only the questions that are due. The question order and the choices are shuffled every time
  4. Press "Save" when you finish. Your progress (level, next due date, correct count) is written to the file too

How it quizzes you until you remember

LevelIf you answer correctly, it comes back
Lv0Tomorrow
Lv1In 3 days
Lv2In 1 week
Lv3In 2 weeks
Lv4In 1 month
Lv5 (mastered)A check in 3 months

A question you miss drops back to Lv0 and comes back tomorrow. In "Quiz from all", answering a question correctly before it is due does not raise its level early (missing it still resets it to Lv0).

CSV format

One question per row. The first row is the header. The progress columns (Level onward) can be left blank.

Question,Answer,Wrong 1,Wrong 2,Wrong 3,Explanation,Level,Next due,Correct count,Wrong count

FAQ

Where are my questions saved?
In a file on your computer (CSV or JSON). Nothing is sent to a server. Your work in progress is also backed up in the browser automatically, so if you close the tab without saving, it is restored the next time you open the tool.
Can I continue on a new computer?
Yes. Your questions and progress (level, next due date, correct count) are all written into the file, so opening that file on a new computer picks up where you left off. Saving it in a Google Drive folder protects you if your computer breaks.
Do mastered questions stop appearing?
Not completely. Each correct answer raises the level and spreads the question out: tomorrow → 3 days → 1 week → 2 weeks → 1 month. Questions that reach the top level, Lv5 (mastered), still come back for a check after 3 months, and drop back to Lv0 if you miss them.
Can I import questions I made in Excel or Google Sheets?
Yes. Open a CSV with the columns in this order: Question, Answer, Wrong 1, Wrong 2, Wrong 3, Explanation. The progress columns can be left blank. In Excel, saving as "CSV UTF-8" is the safest choice.
Is there a limit on the number of questions?
No. Questions are stored in a file on your computer, so you can add as many as you like.
